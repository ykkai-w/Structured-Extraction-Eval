# 指标说明

## 字段准确率

字符串采用 Unicode NFKC 规范化，去除空白并忽略英文大小写后精确比较。字符串数组默认忽略顺序并去重。数值按浮点数比较，布尔值按规范化文本比较。

“可读取回答的字段准确率”只统计能解析为 JSON 对象的回答。“端到端字段准确率”将不可读取回答的字段计为错误。两者应同时报告。

## 无参考信息时的补写率

分母是参考标注为缺失值的字段，分子是模型在这些字段中给出具体值的数量。该指标依赖参考标注是否完整，不能单独用来证明模型虚构了事实。

## JSON 可读取率

分母是状态为 `answered` 的运行单元，分子是能读取为非空 JSON 对象的单元。代码块或简短前言不会直接导致失败。

## 字段结构通过率

每个字段需要具有 `value`、`status`、`evidence` 三个键。`status` 只能是 `stated` 或 `not_stated`。当状态为 `not_stated` 时，不应填写具体值或原文依据。

## 原文依据通过率

对状态为 `stated` 且要求原文依据的字段，检查全部 `evidence` 是否为输入文本中的连续片段。空依据不通过。该指标验证引文存在，不判断引文解释是否合理。

如果一个运行单元的全部字段均为 `not_stated`，该单元没有可检查的原文依据，记为不适用，不进入这一指标的分母。

## 重复运行一致率

以同一记录、提示模板和模型的第一次运行为参照，比较后续运行的规范化字段值。它描述输出变化，不表示哪一次回答更正确。

## 时间与长度

适配器记录一次外部调用的墙钟时间。OpenAI-compatible 适配器在服务提供 usage 时保留输入与输出 token；命令行适配器默认使用输出字符数。不同服务的 token 口径可能不同，不宜直接合并。
